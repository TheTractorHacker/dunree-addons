# Code of conduct

This is a place to review software that other people will run on their servers. Keep it about the work.

* Be respectful and plain. Criticise code, manifests and decisions, not people.
* No harassment, insults, discrimination or personal attacks, here or in private messages about this project.
* A review that says no is not an attack. A rejected add-on can be discussed with reasons, not with pressure.
* Do not post other people's private information.
* Do not use issues and pull requests to advertise.

The maintainers may edit, hide or remove contributions that break these rules, and may block people who keep
breaking them.

To report a problem, write to the maintainer privately: use the contact on the GitHub profile of
@TheTractorHacker. For a malicious add-on use the private report described in [SECURITY.md](SECURITY.md) instead.
